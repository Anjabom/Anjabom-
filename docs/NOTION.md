# 노션 작업 기록 연동 (주간 / 월간)

GitHub 의 작업 기록(병합된 PR, 완료된 이슈, 진행 중·막힌 작업, 팀원별 기여, 릴리스)이 **노션 데이터베이스에 자동으로** 쌓입니다.

| 종류 | 언제 | 기간 |
|---|---|---|
| 주간 | 매주 월요일 09:07 (KST) | 지난주 월 ~ 일 |
| 월간 | 매월 1일 09:13 (KST) | 지난달 1일 ~ 말일 |

각 기록은 다음 두 곳에 남습니다.
- **GitHub 이슈** (`report:weekly` / `report:monthly` 라벨): 팀원 누구나 저장소에서 볼 수 있습니다.
- **노션 데이터베이스 `작업 기록 (주간 / 월간)`** 의 한 행: 유형, 기간, 병합 PR 수, 완료 이슈 수, 진행 중·막힘 수, 참여 인원, 릴리스, GitHub 리포트 링크가 들어갑니다. 페이지 본문에는 팀별 상세 내역과 팀원별 기여가 들어갑니다.

## 노션 쪽 준비 (완료됨)

노션 워크스페이스에 아래 페이지를 이미 만들어 두었습니다 (현재 비공개).
- 페이지: **Anjabom 팀 개발 기록**
- 그 안의 데이터베이스: **작업 기록 (주간 / 월간)**
  - 데이터베이스 ID: `b3085e8e4d8a4db8b1760ee6eae47516`

팀원이 함께 보려면 페이지 우측 상단 **공유** 에서 팀원을 초대하거나, 팀 공간(예: "2026 전국 대학생 AI 자율주행 경진대회")으로 옮깁니다.

## 연결 설정 (관리자 1회, 5분)

### 1. 노션 통합(Integration) 만들기
1. https://www.notion.so/profile/integrations 에 접속해 **새 통합** 을 누릅니다.
2. 이름은 `anjabom-github` 로 하고, 워크스페이스를 선택한 뒤 유형은 **내부(Internal)** 로 합니다.
3. 기능에서 **콘텐츠 읽기, 콘텐츠 업데이트, 콘텐츠 삽입** 을 체크하고 저장합니다.
4. **내부 통합 시크릿**(`ntn_...`)을 복사합니다.

### 2. 데이터베이스에 통합 연결
1. 노션에서 **작업 기록 (주간 / 월간)** 데이터베이스를 엽니다.
2. 우측 상단 `...` → **연결(Connections)** → `anjabom-github` 를 선택합니다.

### 3. GitHub 에 값 등록
저장소 **Settings → Secrets and variables → Actions**
- **Secrets** 탭 → New repository secret
  - Name: `NOTION_TOKEN`, Value: 1-4 에서 복사한 시크릿
- **Variables** 탭 → New repository variable
  - Name: `NOTION_DATABASE_ID`, Value: `b3085e8e4d8a4db8b1760ee6eae47516`

### 4. 시험 실행
**Actions → 진행 리포트 → Run workflow** 에서 `weekly` 를 선택해 실행합니다. 노션 데이터베이스에 새 행이 생기면 성공입니다.

## 자주 묻는 것
- **노션 설정 없이도 동작하나요?** 네. 이 경우 GitHub 이슈만 만들고, 노션 단계는 경고를 남긴 뒤 건너뜁니다.
- **데이터베이스 열 이름을 바꿔도 되나요?** 안 됩니다. `.github/scripts/report.js` 의 `toNotion` 이 열 이름(`제목`, `유형`, `기간`, `병합 PR` 등)으로 값을 넣습니다. 이름을 바꾸려면 코드도 함께 바꿔야 합니다. 열을 새로 **추가**하는 것은 괜찮습니다.
- **기록에 메모를 남기고 싶어요.** 자동 생성된 페이지 본문 아래에 자유롭게 적어도 됩니다 (회고, 다음 주 계획 등).
- **다른 데이터베이스로 바꾸고 싶어요.** 같은 열 구성으로 새 데이터베이스를 만들고, 통합을 연결한 뒤 `NOTION_DATABASE_ID` 변수만 바꾸면 됩니다.
